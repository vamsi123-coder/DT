EXPERIMENT 5 - JENKINS MASTER-SLAVE (CONTROLLER-AGENT) ARCHITECTURE
Source: DT_lab_all_experiments.pdf, Experiment 5 (pages 16-19)

AIM
To configure a Jenkins master/controller and an agent node and run a build on the agent.

REQUIREMENTS
- Jenkins LTS on the master/controller
- Java on the agent machine
- GitHub repository
- Jenkins Git and SSH Build Agents plugins as required by the selected connection method

1. INSTALL JAVA AND JENKINS
Install Java and Jenkins on the master system. Start Jenkins and complete the initial setup.
Open Jenkins in a browser.

2. CREATE A NEW AGENT NODE
- Go to Manage Jenkins -> Nodes.
- Click New Node / Add new node.
- Node name: Slave1.
- Select Permanent Agent.

Enter the details shown in the manual:
- Description: Jenkins agent for distributed build experiment
- Number of executors: 1
- Remote root directory (Windows example): C:\Jenkins\slave1
- Labels: slave1
- Usage: Use this node as much as possible
Save the node.

3. CONNECT THE AGENT
- Open the Slave1 node page.
- Download agent.jar.
- The manual uses the folder C:\Jenkins\slave1.
- Place agent.jar in that folder.
- Copy and execute the exact agent connection command shown by Jenkins. It includes the
  controller URL, agent name and secret. Do not reuse another machine's secret.
- Confirm the node changes to Online / connected.

4. CREATE THE AGENT BUILD JOB
- Click New Item.
- Job name: Slave_function.
- Select Freestyle project.
- Under Source Code Management, select Git.
- Repository URL used in the manual:
  https://github.com/vamsi123-coder/Jenkins
- Branch Specifier: */main.
- Under General, enable "Restrict where this project can be run".
- Enter label: slave1.

5. ADD A BUILD STEP
The manual asks to run app.py from the repository. Select the appropriate build step for
the agent operating system.

Example app.py content:
print("This Python program is running on the Jenkins agent.")

For a Windows agent, use Execute Windows batch command:
python app.py

For a Linux agent, use Execute shell:
python3 app.py

6. SAVE AND RUN
- Click Save.
- Click Build Now.
- Open the build number -> Console Output.
- Confirm the job ran on the Slave1 agent and completed successfully.

NOTE
The agent connection command and secret are generated by your own Jenkins controller.
Copy them from the Slave1 node page. The manual's example uses a Windows agent directory.
